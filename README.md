# After Hours v7 — Action Edition

Free, offline-capable once saved, single-file browser game for 2–8 consenting adults.

**What changed:** 146 original action-first built-in challenges; explicit settings & boundary conversations are not placed in the challenge deck. Quick physical dares, real turn/player assignment, original stick-figure diagrams, matching rules, timed challenges, private custom cards, import/export.

### Deployment
Upload **only `index.html`** into the root of your GitHub Pages repository, replacing the prior file. The app has embedded CSS, JS and data. Older `app.js`, `cards.js`, `quick-cards.js`, `styles.css`, and `sw.js` are not required.

The app automatically migrates players/preferences and private custom cards from v6 on the same browser; it resets the active session because the built-in card IDs changed.

This is an original game inspired by publicly stated Jadegreen mechanics, not a copy of its artwork, prompts, or source code. All sexual categories can be opted into; the built-in challenges are suggestive, non-graphic, and the private card editor supports participant-authored challenges.
